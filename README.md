# 勇者奶蛙传 · 修改版

在线玩：<https://zhuoxiaojun0217.github.io/naiwa-trainer/>

手机建议横屏打开；首次进入时修改器面板会收起，点屏幕左侧的「🐸 修改器」胶囊展开。

- 单机作弊：无敌、一击必杀、无限能量、自动开火、无限冲刺、黄桃自由、移动加速、超级大笑
- 快捷操作：回满血、清屏、下一章、直达终章、重置存档
- 进度保存在本域名下，和官方页面的旧进度不互通
- 纯前端修改，不联网、不上传；仅用于学习与单机娱乐，游戏素材版权归原作者

本仓库只有一个静态页 `index.html`，通过 `<base>` 加载官方 CDN 上的游戏资源，没有镜像游戏本体。
